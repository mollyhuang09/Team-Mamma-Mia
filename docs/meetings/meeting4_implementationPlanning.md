## Summary

In this meeting, we discussed the implementation plan for the project. We decided that the app will be built using **Kotlin** and **Firebase**.

We also agreed on the overall structure of the app and how the main pages will be organized.

## Project Structure

The app will have three main tabs:

* Start Page
* Add Location
* Settings

The Start Page will include both a map view and a list view. When a user clicks on an entry from the list, they will be taken to a location details page.

The four main pages of the app will be:

* Map and list view
* Location details view
* Add location view
* Settings view
